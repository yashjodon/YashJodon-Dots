# Security Policy

Thank you for helping keep **YashJodon-Dots** secure.

Security is important for everyone using this project. If you discover a security issue, please report it responsibly.

---

# Supported Versions

| Version | Supported |
|----------|-----------|
| 1.x.x | ✅ |
| 0.x.x | ⚠️ Best Effort |

Development versions may change frequently and may not receive security updates.

---

# Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, contact the maintainer privately.

GitHub:
https://github.com/yashjodon

Email:
jadonyash716@gmail.com

---

# Please Include

When reporting a vulnerability, include:

- Operating System
- Linux Distribution
- Hyprland Version
- Waybar Version
- Steps to Reproduce
- Expected Behavior
- Actual Behavior
- Screenshots (if applicable)
- Log files (if available)

---

# Response Timeline

We aim to:

- Acknowledge reports within **72 hours**
- Provide updates as progress is made
- Release a fix as quickly as possible

Please note that response times may vary.

---

# Scope

This policy covers:

- Installation scripts
- Hyprland configuration
- Waybar configuration
- Hyprlock configuration
- Shell scripts
- Project utilities

---

# Out of Scope

The following are generally outside the scope of this policy:

- Third-party software bugs
- Linux distribution bugs
- Hardware-specific issues
- Unsupported modifications

---

# Responsible Disclosure

Please allow time for the issue to be investigated before publicly disclosing it.

Responsible disclosure helps protect everyone using the project.

---

# Security Philosophy

YashJodon-Dots aims to be:

- Minimal
- Transparent
- Easy to audit
- Open Source
- Privacy Friendly

No telemetry.

No tracking.

No unnecessary network activity.
