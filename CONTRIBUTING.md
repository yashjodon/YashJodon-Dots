# Contributing to YashJodon Dots

First of all,

Thank you for taking the time to contribute to **YashJodon Dots** ❤️

The goal of this project is to create a beautiful, minimal, fast and production-ready Hyprland setup that anyone can use.

---

# Before You Start

Please read the following documents first.

- README.md
- STYLE_GUIDE.md
- LICENSE

---

# Our Principles

Every contribution should follow these rules:

- Keep it minimal.
- Performance comes first.
- Do not add unnecessary features.
- Keep configurations clean.
- Make changes easy to understand.
- Follow existing naming conventions.

---

# Ways You Can Contribute

You can help by:

- Fixing bugs
- Improving documentation
- Creating wallpapers
- Improving scripts
- Fixing configuration issues
- Improving compatibility
- Suggesting new ideas
- Performance optimization
- Accessibility improvements

---

# Reporting Bugs

When opening an issue include:

- Linux Distribution
- Hyprland Version
- GPU
- Screen Resolution
- Error Message
- Steps to Reproduce
- Expected Behavior
- Screenshots (if possible)

Example:

Distribution:
Arch Linux

Hyprland:
0.55.4

GPU:
Intel UHD 620

Problem:
Wallpaper does not load after reboot.

Expected:
Wallpaper should load automatically.

---

# Feature Requests

Before requesting a feature ask yourself:

Does this improve usability?

Does it fit the minimal philosophy?

Will most users benefit from it?

If the answer is "No", it probably shouldn't be added.

---

# Code Style

Shell Scripts

- Use Bash
- Keep functions small
- Add comments where needed
- Avoid duplicated code

Configuration Files

- Keep formatting clean
- Preserve indentation
- Group related settings
- Add comments for important options

---

# Commit Messages

Good examples:

feat: add new lockscreen theme

fix: wallpaper loading issue

fix: improve battery script

style: clean configuration formatting

docs: update README

perf: optimize startup

Avoid:

update

fix

changes

misc

test

---

# Pull Requests

Please make sure:

- The project builds correctly
- No existing feature is broken
- Configuration is tested
- Documentation is updated
- Screenshots are included if UI changes

---

# Wallpapers

Recommended:

- Dark
- Minimal
- High Resolution
- 16:9
- 21:9
- Soft Lighting
- Cyber Workspace
- Rain
- Night City
- Cozy Desk

Avoid:

- AI artifacts
- Low resolution
- Heavy neon
- Bright colors
- Watermarks

---

# Design Philosophy

We prefer

✔ Simplicity

✔ Speed

✔ Readability

✔ Consistency

✔ Stability

instead of

✘ Fancy effects

✘ Heavy animations

✘ RGB overload

✘ Unnecessary widgets
