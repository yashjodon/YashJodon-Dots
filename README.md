# 🌑 YashJodon-Dots

> **Minimal • Productive • Distraction-Free Hyprland Experience**

A modern Hyprland dotfiles project inspired by clean design principles rather than flashy effects.

Built for people who prefer focus, simplicity and elegance.

# 🎯 Philosophy

YashJodon-Dots follows one simple idea:

> Less clutter.
> Better focus.

Instead of RGB effects, anime themes or overloaded bars,
this project provides a calm and minimal workspace.

---

# 📦 Features

- Clean Hyprland configuration
- Minimal Waybar
- Premium Hyprlock
- Beautiful wallpaper collection
- Glassmorphism UI
- Rounded corners
- Smooth animations
- Dark color palette
- JetBrains Mono Nerd Font
- One-command installer
- Lightweight configuration
